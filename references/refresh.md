# Refresh the source map

Use only when the user requests a source-map refresh. Normal questions fetch the mapped originals without this workflow.

1. Open each public source in `sources.md` and verify its title, URL, availability, scope, and visible version or update date.
2. Follow official season-hub links for the latest Competition Manual, Team Updates, Q&A, and field resources. Treat community channels as discovery sources, not governing authority.
3. Update only changed entries, observed dates, and limitations. Retain temporarily unavailable sources with a clear status instead of silently replacing them.
4. Re-fetch changed originals and report the actual changes and remaining gaps concisely. Do not claim an unchanged list without checking it.

## Refresh boundary

The skill uses fresh original-source retrieval on demand and explicit source-map refreshes. It does not run between conversations. A requested periodic refresh needs a real automation; do not treat a skill instruction as a scheduler.
